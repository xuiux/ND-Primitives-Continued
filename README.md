# ND Primitives · 非破坏性参数化基础几何体（Blender 5.3 适配版）

本项目是 [Non-Destructive Primitives](https://extensions.blender.org/add-ons/non-destructive-primitives/) 的更新分支，在原扩展的基础上适配了最新的 **Blender 5.3**，并保留了向下兼容能力（最低 Blender 4.2）。原扩展作者为 **Dan-Gry**，本项目为非官方维护版本。

它把常用的基础几何体做成由几何节点（部分为传统修改器）驱动的参数化对象：添加之后，随时可以在修改器面板中调整分段、半径、高度等参数，而不必回到编辑模式重建模型。

## 功能特性

### 参数化、非破坏性建模

添加的几何体本质上是「单顶点网格 + 几何节点修改器」，所有形变都由节点组实时生成，原始网格始终保持最小状态。你可以：

- 在修改器面板中反复调节参数，模型实时更新；
- 随时应用修改器将其固化为普通网格；
- 保留完整建模历史，方便后期修改。

内置 14 种几何体：

| 几何体 | 说明 |
| --- | --- |
| Grid（栅格） | 可调尺寸、X/Y 顶点数 |
| Cube（立方体） | 可调尺寸、细分 |
| Circle（圆形） | 可调顶点数、填充类型 |
| UV Sphere（UV 球体） | 可调分段、环数、半径 |
| Ico Sphere（Ico 球体） | 可调细分、半径 |
| Cylinder（圆柱体） | 可调顶点数、半径、深度 |
| Cone（圆锥体） | 可调半径上下端、深度 |
| Torus（圆环） | 可调主/次半径与分段 |
| Quad Sphere（四边面球体） | 四边面拓扑球体 |
| Capsule（胶囊体） | 可调半径、高度 |
| Quad Capsule（四边面胶囊体） | 四边面拓扑胶囊体 |
| Mod Cylinder（修改圆柱体） | 基于 Screw 修改器的参数化圆柱 |
| Spiral（螺旋） | 可调圈数、起止半径、高度 |
| Tube（管状体） | 可调主/次半径、环分辨率 |

### 面向新版本 Blender 的适配

- **修改器输入读写兼容层**：优先使用新版 `modifier.properties.inputs` 接口访问几何节点修改器输入，并保留旧版 `modifier[identifier]` 路径作为回退，从而同时兼容 Blender 4.2 与 5.3。
- **节点组版本管理**：从 `Primitives.blend` 加载节点组时会比对版本号，自动升级旧对象使用的节点组，并对 `Set Material to Index 0`、`Fix Pivot` 等辅助节点组做重映射与清理。
- **界面中文化**：操作符、菜单项以及节点组输入插槽名称均提供中文显示（如 `Radius` → `半径`、`Segments` → `分段`），同时保留内部逻辑名映射，避免版本升级后插槽改名导致功能失效。

### 自动缩放

新增几何体默认按当前 3D 视图的视距自动计算大小，使模型在视口中保持合适比例。可关闭自动缩放并手动指定尺寸，也可在偏好设置中调整「最小自动缩放」下限。

### 视口操控器（Gizmo）

Blender 4.3 及以上版本中，几何体节点组内置了旋转/线性操控器，可直接在视口中拖拽调整关键参数；偏好设置中可统一显示或隐藏操控器，并反转旋转操控器的方向。

### 编辑模式自动应用

开启「进入编辑模式时自动应用修改器」后，进入编辑模式时会把修改器结果烘焙进网格，便于直接编辑顶点；可选择应用后保留修改器（仅关闭视口显示）或直接删除修改器。

### 添加菜单与饼菜单

- 添加菜单支持四种显示方式：直接并入「网格 → 添加」、作为网格菜单中的独立分类、作为顶层「添加」菜单分类，或完全隐藏。
- 绑定 **Shift+A**（物体模式）的八向饼菜单可快速添加常用几何体，每个方位都能在偏好设置中重新指定，默认布局为：

  | 方位 | 默认项 |
  | --- | --- |
  | 上 | Grid |
  | 下 | Cylinder |
  | 左 | UV Sphere |
  | 右 | Cube |
  | 左上 | Mod Cylinder |
  | 右上 | Other（打开 Blender 原生添加菜单） |
  | 左下 | Quad Sphere |
  | 右下 | Circle |

  每个方位还可选择「自定义操作符」，填写操作符 ID 与显示名称后即可调用任意 Blender 操作符。

> 注意：饼菜单默认占用物体模式的 **Shift+A**，会覆盖 Blender 默认的「添加」菜单快捷键；饼菜单中的「Other」项可以直接打开 Blender 原生添加菜单。如不习惯，可在 `偏好设置 → 键位映射` 中修改，或将「ND Primitives 显示位置」设为「无」并改用菜单添加。

## 安装

1. 将本项目打包为 zip（保持 `blender_manifest.toml` 位于压缩包根目录）；
2. 在 Blender 中打开 `编辑 → 偏好设置 → 扩展（Get Extensions）`，点击右上角下拉菜单选择 **从磁盘安装（Install from Disk）**，选中 zip 包；
3. 启用 **ND Primitives** 扩展。

开发调试时，也可将整个目录放入 Blender 的 `scripts/addons` 或扩展目录后手动启用。扩展清单中声明了 `files` 权限，用于从插件目录导入 `Primitives.blend` 中的几何节点资产。

## 使用

1. 在物体模式下通过 `添加 → 网格 → ND Primitives` 选择几何体，或按 **A** 打开饼菜单；
2. 添加后会自动切换到修改器标签页（可在偏好设置中关闭）；
3. 在修改器面板中调整几何节点输入参数，或在视口中拖拽操控器；
4. 需要直接编辑网格时进入编辑模式，修改器会按偏好设置自动应用。

## 偏好设置

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 进入编辑模式时自动应用修改器 | 开 | 进入编辑模式时把修改器结果应用到网格 |
| 删除修改器 | 关 | 应用后删除修改器；关闭时仅关闭视口显示 |
| 自动切换到修改器标签页 | 开 | 添加几何体后自动切换到修改器面板 |
| 显示操控器 | 开 | 显示节点组内置操控器（Blender 4.3+） |
| 反转旋转操控器方向 | 关 | 反转旋转操控器的拖拽方向 |
| 原点在底部 | 关 | 新建几何体默认原点位于底部（重启 Blender 后生效） |
| 最小自动缩放 | 0.01 | 自动缩放允许的最小尺寸 |
| ND Primitives 显示位置 | 网格菜单 | 控制添加菜单的集成方式 |

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `__init__.py` | 扩展注册入口、msgbus 订阅与快捷键注册 |
| `add_nd_primitive.py` | 核心操作符、节点组加载/版本管理/插槽本地化 |
| `add_menu.py` | 添加菜单集成与菜单绘制 |
| `pie_menu.py` | 八向饼菜单 |
| `addon_preferences.py` | 偏好设置、几何体清单与中文名称映射 |
| `mesh_utils.py` | 自动缩放计算、编辑模式应用、Mod Cylinder 构建 |
| `utils.py` | 修改器输入兼容层、快捷键、Gizmo 显隐与方向 |
| `Primitives.blend` | 几何节点资产库 |
| `blender_manifest.toml` | Blender 扩展清单 |

## 兼容性

- **已验证适配**：Blender 5.3
- **最低版本**：Blender 4.2（扩展清单声明）
- **操控器**：需要 Blender 4.3 及以上
- **自定义操作符（饼菜单）**：依赖 UV Toolkit 扩展提供的 `uv.toolkit_execute_custom_op` 操作符
- **快捷键冲突**：默认占用物体模式的 Shift+A（Blender 默认为添加菜单），可按上文说明调整
